# CMS Web Finder 2.2.1

Плагін WordPress: пошук сайтів за CMS / країною / мовою з перевіркою **по коду сторінки**, збережені списки, шаблони листів і розсилка з прогресом та історією.

Папка плагіна залишилась `cms-checker`, тому 2.0.0 встановлюється поверх 1.1: старі результати, нотатки та шаблон переносяться автоматично (список «Імпорт зі старої версії»).

## 2.2.1
- Визначення CMS спирається на конкретні технічні шляхи, класи, JavaScript-об'єкти та метадані generator; загальні згадки `shopware`/`modx` більше не є ознакою.
- Для CMS generator коректно обробляється будь-який порядок атрибутів у meta-тезі.
- Пошукові запити використовують технічні відбитки CMS/плагінів і рівномірно охоплюють вибрані платформи в межах ліміту 40 запитів.
- Якщо розмітка пошуковика не відповідає відомому формату органічних результатів, навігаційні та рекламні посилання не додаються як кандидати.

## 2.2.0
- **Точніший відбір:** текстові згадки назви CMS не вважаються підтвердженням; перевіряються технічні ознаки в розмітці та скриптах. WooCommerce і HivePress є окремими варіантами фільтра.
- **Україна:** для регіонального фільтра приймаються лише домени з `.ua` наприкінці, включно з `.com.ua` та `.org.ua`; телефон або валюта самі по собі не проходять.
- **Мова:** підтверджується атрибутами `lang` і `hreflang`; здогад за текстом більше не використовується як підстава для відбору.
- Без вибору CMS залишаються сайти з визначеною CMS; «Не визначено» відхиляється. Перевірка TLS-сертифікатів увімкнена.

## 2.1.0
- **Шаблони пошуку:** збереження/завантаження/видалення наборів параметрів (CMS, країна, мова, тип, категорії, джерела, ліміт). При першій активації додаються «WooCommerce · Україна», «Joomla · Україна», «WordPress · Україна».
- **Окремий розділ «Свій список»** для перевірки власних доменів (з фільтрами або без них); «Пошук» тепер лише за параметрами.
- **Джерела:** замість чотирьох галочок — «Список доменів зони» і «Пошуковики» (заблоковані пропускаються автоматично). Пошуковики запускаються першими (вони враховують категорії/теги), зона добирає до ліміту.
- **Розсилка:** вибраний шаблон можна редагувати, зберегти як новий або видалити прямо в списку.
- Опція «відсіювати сайти без збігу з категоріями/тегами».

## 2.0.1
- Черга перевірки більше не зациклюється на домені, результат якого не збережено: записи захоплюються (`checking`), помилки зберігання/збої фіксуються як «недоступний», а після 15 збоїв підряд перевірка зупиняється з текстом реальної помилки.
- Перевірка одного сайту обмежена ~24 с (багато хостингів обривають запити на 30 с).

## Розділи
- **Пошук** — параметри (CMS, країна, мова, тип сайту, категорії/теги), джерела кандидатів, власний список доменів, прогрес-бар, список знайдених сайтів у реальному часі.
- **Списки** — усі збережені списки (наприклад «Joomla · Україна», «WordPress · Україна»). Відкриваються будь-коли, можна допошукувати/продовжувати перевірку, перейменовувати, видаляти, експортувати.
- **Шаблони листів** — створення/редагування/видалення, групи за темою (Joomla, WordPress, Плагіни…), змінні `{url} {domain} {site_title} {cms} {version} {latest_version} {email}`, попередній перегляд. При першій активації додаються три приклади.
- **Налаштування** — відправник, пауза між листами, підпис, остання версія CMS (авто або вручну), роздільник CSV, кількість паралельних перевірок, тестовий лист.

## Розсилка
У списку: «Вибрати всі на сторінці» → «Вибрати всі N у списку» (або галочки на окремих сайтах) → шаблон (або «Створити новий шаблон…») → «Надіслати вибраним». Видно прогрес-бар, кількість успішних і невдалих. У кожного сайту зберігається відмітка: коли надіслано і чи вдалось (плюс текст помилки та історія в таблиці `cmsf_log`).

## Як працює відбір
Сайт потрапляє до списку, лише якщо код його головної сторінки підтверджує вибрані параметри:
- **CMS / платформа / плагін** — за технічними ознаками розмітки та скриптів, а не за текстовою згадкою. Для WooCommerce додатково перевіряється публічний Store API, якщо інші ознаки WordPress уже знайдено.
- **Країна «Україна»** — лише доменна зона `.ua` (включно з `.com.ua`, `.org.ua` тощо). Телефон і валюта не замінюють доменну ознаку.
- **Мова** — за `<html lang>` та `hreflang`; якщо вибрана мова не задекларована, сайт відсіюється.
Відхилені сайти не показуються за замовчуванням (фільтр «Відхилені» покаже причину).

## Версії CMS
Остання версія визначається автоматично (WordPress API, GitHub-теги Joomla/Drupal) і кешується на 12 годин; у Налаштуваннях її можна вписати вручну — вона має пріоритет. Сайти зі старішою версією позначаються «застаріла».

## Експорт
Кнопка «Експорт CSV» — вибрані сайти або всі за поточним фільтром. Файл у UTF-8 з BOM; роздільник `;` (для українського Excel) змінюється в Налаштуваннях.

## Джерела кандидатів
- **Список доменів зони (Majestic)** — найнадійніший: безкоштовний рейтинг ~1 млн популярних сайтів, з нього беруться домени потрібної зони. Завантажується один раз (~100 МБ, шматками по 8 МБ) у `wp-content/uploads/cms-web-finder/`.
- **Bing / DuckDuckGo / Mojeek** — запити будуються під обрану CMS; хостингові IP пошуковики часто блокують, це видно в журналі.
- **Власний список** — вставка або файл TXT/CSV.

## Вимоги
WordPress 5.3+, PHP 7.4+. Для розсилки потрібна робоча пошта сервера (рекомендовано SMTP-плагін); перевірити можна кнопкою «Надіслати тестовий лист».
